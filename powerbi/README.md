# Power BI Dashboard Implementation Guide

This directory houses the semantic model schema definitions and templates for Power BI consumption.

### Included Dashboard Panes
1. **Executive Product Overview**: Real-time DAU, WAU, MAU, and stickiness ratios ($DAU / MAU$).
2. **Feature Drop-Off Funnels**: Conversion rates from `session_start` to `action_completed` segmented by module.
3. **Sprint Velocity Impact**: Feature usage spikes post-deployment compared against previous release baselines.

### Setup Instructions
1. Open **Power BI Desktop**.
2. Connect to the PostgreSQL instance or import the synthetic CSVs generated by `pipelines/telemetry_generator.py`.
3. Set relationships as defined in `powerbi/data_model_schema.json` (Star Schema: 1-to-many from dimensions to `fact_user_events`).
4. Copy measures from `dax/kpi_measures.dax` into your Model Measures table.
